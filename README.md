# ai-pm-portfolio

Learning portfolio documenting my 240-day path from SaaS PM to AI Product Manager,
targeting AI PM roles at top AI companies. Built in public, one artifact at a time.

## Who I am

Senior Product Manager with 6 years of SaaS experience. I'm systematically building
hands-on AI skills — not just familiarity, but the ability to design AI systems,
run evals, and ship prototypes alongside engineers. This repo is the evidence trail.

## What's in here

This repo holds artifacts produced across the AI PM curriculum, plus the state files that track my progress.

- `phase-0-foundations/` — Module 0 work (mental models, setup, command line, Git)
- `phase-N-*/` — one folder per phase as I reach it
- `STUDY_LOG.md` — append-only history of every learning session
- `PROGRESS.md` — current state, regenerated from the log
- `CHANGELOG.md` — curriculum updates as the AI field evolves

# Jira setup

Create a free team-managed Kanban project:

- Name: Save & Recall
- Key: SH
- Board: Build & Product
- Releases: 0.1 Capture, 0.2 Understand, 0.3 Recall, 0.4 Act, 1.0 Personal Pilot
- Work types: Epic, Story, Task, Bug, Enhancement, Spike
- Workflow: Inbox, Ready, In Progress, Validate, Done, Blocked, Parked, Won't Do
- WIP limit: two across In Progress and Validate

Import `initial-backlog.csv`, then map Summary, Issue Type, Description, Priority, Labels, and Fix Version. Jira remains the work source of truth; do not mirror routine issues into GitHub Issues.
